# OIBSIP

A collection of three Python projects developed as part of the **OIBSIP (Oasis Infobyte Internship Program)**. Each project focuses on applying Python programming concepts and libraries to build practical applications.

## 📂 Projects

### 1. BMI Calculator

A Python-based (tkinter) application that calculates **Body Mass Index (BMI)** based on the user's height and weight.

**Key features:**

* Accepts height and weight as input
* Calculates BMI
* Displays the corresponding BMI category
* Simple and user-friendly interface

📁 [`BMI-Calculator/`](./BMI-Calculator)

---

### 2. Random Password Generator

A Python application that generates **secure and randomized passwords** based on user requirements.

**Key features:**

* Generates random passwords
* Supports combinations of letters, numbers, and special characters
* Customizable password length
* Uses Python's built-in libraries for randomization

📁 [`Random-Password-Generator/`](./Random-Password-Generator)

---

### 3. Weather App

A Python-based weather application that provides weather information for a specified location using a weather API.

**Key features:**

* Accepts a location as input
* Retrieves current weather information
* Displays relevant weather details
* Uses Python libraries to communicate with the weather API

📁 [`Weather-App/`](./Weather-App)

---
